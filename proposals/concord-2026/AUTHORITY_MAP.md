# Concord 2026 Reconciliation — Authority Map

Status: PROPOSAL / NON-CANONICAL
Branch: proposal/concord-2026-reconciliation
Purpose: establish source authority for recovery and reconciliation before any canon promotion.

## Governing principle

Do not silently improve, normalize, reconcile, or overwrite recovered material during recovery. When sources disagree, record the conflict and defer resolution.

## Authority tiers

### Tier A — Explicit locked/final source canon
Highest authority unless a demonstrably later user-approved decision supersedes it.

Examples:
- documents or chat artifacts labeled FINAL CANON, LOCKED, SINGLE SOURCE OF TRUTH, or equivalent
- Trilogy Beats.docx, labeled consolidated Final Canon for Veil / Neon / Loom
- character identity documents in GitHub explicitly marked locked/final

### Tier B — Explicitly approved development outputs
Material generated in a development workflow and explicitly accepted/archived by the user.

Examples:
- Book 1 Episode Expansion outputs that follow the generate -> archive -> confirm -> proceed workflow
- structural episode shells intentionally archived as continuity anchors

### Tier C — Current GitHub developed canon
Developed, non-placeholder repository files that clearly represent completed migration work.

Important limitation:
- a TODO or empty scaffold in GitHub does not override richer approved material that was never migrated.
- current GitHub wins over older material only where the repository contains an actual developed statement and provenance/order indicate it is newer.

### Tier D — Assistant-generated but unapproved material
Useful as recovery evidence only. Never auto-promote to canon.

### Tier E — ChatGPT project memory / summaries
Navigation and discovery aids only. Not canon authority.

## Temporal rule

Where two sources have the same authority tier, prefer the later explicit user-approved decision. If chronology is uncertain, mark CONFLICT rather than infer.

## Conflict handling

Use one of the following statuses:
- FOUND — source exists and is internally consistent
- VERIFIED — supported by at least two independent authoritative sources or by authoritative source plus later migration
- PARTIAL — substantial content recovered but exact source artifact or wording is incomplete
- CONFLICT — apparently authoritative sources disagree
- SUPERSEDED — later approved material clearly replaces earlier material
- MISSING — expected artifact not recovered
- OPEN — intentionally unresolved creative decision
