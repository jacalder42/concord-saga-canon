## 0. PURPOSE AND APPROVAL GATE

This manifest consolidates the 2026 forensic recovery and editorial casting passes into one migration control document.

It is deliberately a **decision manifest**, not a new character bible.

Nothing in this file by itself promotes proposal material into Tier-1/source canon.

After author approval:
1. search source canon, temporal canon, beat bibles, manifests, and rules-dependent references for each historical identity;
2. classify each occurrence as transfer / rename / merge / anonymize / retire / contradiction;
3. migrate in controlled batches;
4. validate chronology and relationship effects;
5. update recovery/decision ledgers;
6. only then retire obsolete proposal-era aliases.

Authority:
A current author rulings > B authoritative historical backups > C approved development > D summaries/Notion > E recollection.

Legend:
- KEEP = retain current identity/function.
- RENAME = same/rebuilt identity under new name.
- MERGE = material transfers to another retained identity.
- DEMOTE = may remain local/cameo; no saga-recurring obligation.
- RETIRE = remove as current reader-facing recurring identity.
- RECOVER MORE = protect slot/name; do not invent missing facts.
- HOLD = potentially useful but not ready for promotion.
- OPEN = ending/chronology detail requires later decision.
- LOCKED = current author ruling or already protected saga fact.
