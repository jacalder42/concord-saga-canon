# Editorial principle

A saga milestone records a durable changed state.

It is not:
- a travel itinerary;
- every set piece;
- every relationship rung;
- every city observation;
- every act climax.

The replacement set below intentionally reduces spectacle-only rows while adding missing durable character/relationship turns.
