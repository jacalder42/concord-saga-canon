# `manuscript/` — authored narrative prose

**Authority:** none. Ruling 10 (2026-09-21): *"Location is not authority … Canon is what
the substrate says. Prose in the repo is material and output; it is not a ruling."*

**Provenance:** every file here is `authored`, with a date. Never `derived`, never
`recovered`.

## Rules

1. **Authored, not generated.** Written by the author, or at the author's explicit
   direction.
2. **Never rewritten by a tool without explicit instruction.** Every other artifact in this
   repository is regenerable; this one is not. A derived container can be rebuilt from its
   source if it is wrong. A rewritten paragraph is gone.
3. **Outside substrate validation.** Not scanned, not counted, never part of canon-scope.
4. **The substrate still governs.** Prose living here does not make it canon, and does not
   override `rules/` or `canon/`. If prose and substrate disagree, that is a finding to
   record under `CLAUDE.md` §4 — not a licence for either to overwrite the other.

## Why this directory exists

The deliverable is nine books. A canon repository that structurally cannot hold the work it
governs gets abandoned when writing starts, or the writing happens elsewhere and the two
diverge — the exact failure the containment model exists to prevent.

## What has not changed

**`E19` and beyond remain prohibited.** `CLAUDE.md` §4: E19 is named but never built, and
the prohibition stands until James lifts it. **This directory does not lift it.** Ruling 10
created somewhere for prose to live; it did not authorize writing any.
