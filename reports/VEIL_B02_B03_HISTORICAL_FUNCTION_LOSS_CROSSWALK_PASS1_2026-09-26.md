# Veil B02–B03 Historical Function-Loss Crosswalk — Pass 1

**Status:** EDITORIAL RECONCILIATION / NONCANONICAL  
**Date:** 2026-09-26  
**Purpose:** Test the B02/B03 Pass-1 episode architectures against recovered historical functions so compression cannot silently delete high-value material.  
**Does not change:** canon, episode count, EBCI status, milestone grid, Warehouse physics, exact scene staging, or POV quotas.

## Classification

- **KEEP** — function survives substantially as recovered.
- **MERGE** — preserve function inside a stronger combined episode/window.
- **MOVE** — preserve, but historical coordinate is obsolete.
- **REFRAME** — preserve story job while replacing obsolete mechanics/chronology/terminology.
- **RETIRE** — function itself should not survive.
- **HOLD** — potentially useful, but insufficient evidence or downstream dependency prevents placement.

A historical episode number is a **source coordinate**, not a promise to retain numbering.

# 3. Recovered material Pass 1 under-protected

These are genuine **function-loss risks**, not requests for more plot.

## A. Caro / Elisabet

Pass 1 was too cautious.

Recovered Veil relationship chronology supports:
- **B02:** safety -> unmistakable attraction; a Lantern-function beat in which Elisabet's care matters differently to Caro.
- **B03:** future-facing vulnerability **and first kiss** before Warehouse.
- B04 then receives partnership/payoff rather than having to begin the relationship.

**Action for Pass 2:** make these relationship-state changes explicit while leaving exact scene choreography open.

## B. Baz as a social human being

Baz needs more than competence.

Before Warehouse protect:
- Lucien/Baz shorthand, warmth and disagreement;
- Baz/Seraphine mutual respect;
- at least light Baz/Caro/Elisabet ensemble familiarity;
- Baz known at Velvet Vein / by Trip enough that absence is socially legible;
- at least one ordinary future assumption in B03.

**Action for Pass 2:** insert/merge these into existing low-pressure episodes; do not create a “Baz farewell tour.”

## C. Supporting cast as continuity

The old material contains useful functions that should not collapse into “civic POV.”

Preferred recurring carriers:
- **Mara/M or Arianna:** Filament/community care and grounding limits;
- **Leila Broussard:** triage/medical continuity;
- **Ramon Espina:** infrastructure/transit;
- **Shirin Petrov:** incomplete civic/data aggregation;
- **Kesi Albright:** public/cultural interpretation;
- **Trip:** social temperature/hospitality.

**Action for Pass 2:** assign only where function naturally recurs. Do not make all six a standing team.

## D. Place and culture

Protect:
- Velvet Vein progression: ordinary life -> rumor hub -> truth-pressure/community support;
- NOLA streets/transit/weather/music/food as lived environment rather than anomaly backdrop;
- Marrakesh as a person/place, not a data pin;
- Warehouse District as ordinary working/civic geography before it becomes a scar.

## E. Humor / wonder / reward

Historical expansions overproduced anomaly mechanics but still contained useful ordinary-life texture. The new architecture must not let compression remove the **negative space** while preserving every system beat.

Pass-2 minimum:
- B02 each act: at least one episode/window whose primary value is ordinary life, humor, intimacy, place or benign wonder.
- B03 A1/A2: at least one such basin each.
- B03 A3 after Warehouse: no comedy requirement; use stillness/community care instead.

This is a diagnostic, not a quota.
