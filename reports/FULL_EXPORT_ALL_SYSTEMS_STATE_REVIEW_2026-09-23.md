# Concord Saga — all systems state review from the full export

**Date:** 2026-09-23  
**Status:** FORENSIC SYSTEM REGISTER / EDITORIAL RECOMMENDATION — NON-CANONICAL  
**Purpose:** answer what has actually been developed, what exists in the current substrate, and what needs recovery or adjudication before EBCI. No canon file or B01 episode order is amended.

## Method and authority limit

I opened the author-supplied **164,146,176-byte** TAR, `2025-11-01__Concord_Saga_CSVs__6906955c.tar`, and verified **72 full JSON conversations plus 72 paired Markdown renderings** (Nov. 2025–Sept. 2026). The original JSON is richer than the sanitized browser HTML; it is full text **for those included conversations**, not proof of total account coverage. This pass indexed all 72 by system vocabulary, read the actual passages for the newly disputed everyday systems, and compared with the default-branch GitHub tree (434 entries), representative current files, Notion recovery and the prior pre-EBCI audits. **This is a broad state review, not a 7.5-million-word line audit.** A keyword count is a navigation aid, never proof of durable canon.

Source tiers follow [author decisions](../recovery/CANON_DECISIONS_2026-09-18.md) and the [recovery ledger](../recovery/RECOVERY_LEDGER_2026.md): later explicit rulings and accepted narrative architecture outrank assistant claims of “final canon,” Notion labels and old memory inflation. The repository itself mixes current rules, old rule labels, Tier-D recovered sources, proposals and scaffolds. File existence does not settle status.

**Classification below:** **CURRENT** = usable with known later rulings; **RECOVERED** = full source or Notion attests historical development; **RECONCILE** = conflicting versions or missing implementation; **OPEN** = no adequate operational model or explicit decision; **SUPERSEDED** = later ruled against. A row can have several statuses on different axes.

## Overall finding

The saga has **far more developed historical systems than the current directory layout suggests**. The Nov. 30 full conversation, `2025-11-30__Project_review_and_guidance__692c44d7.md`, includes a compiled Track-1 tech/travel/fashion reference (~7790–8145), a weapons/tools palette (~8147–8414), evidence/dead-drop and translation bibles (~4990–5420), power/charging by era/class (~4783–4980), and an author-requested uniforms/workwear bible (~7353–7621). At ~10367–10477 it explicitly lists still-needed context systems: palette, **weather operations**, standard everyday kits, **general economy/barter**, **civic/social order**, resopunk background infrastructure and material texture. Subsequent Dec. 1 development and Notion pages add material, so this historical gap list is a lead, not the final verdict.

Conversely, `rules/Channels/CHANNELS_OVERVIEW.md` still calls MT “Mortal Technology” and VT “Veil-Touch,” despite [current channel rulings](../recovery/CHANNEL_NAMES_RULING_2026-09-19.md) and `canon_rules.json` specifying MissingThread / VeilThread / LuminousThread. The repository cannot be classified “all systems current” while such collisions remain.

## Cross-system collisions that matter most

1. **Names and authority:** `canon_rules.json` resolves MT/VT/LT while old Channel files retain retired headings; “Authoritative Canon” in a Phase 1A source is not newer than the author ruling.
2. **Visual precedence:** the full Nov. 30 author message expressly identifies the pasted **Hybrid VFX Canon** as latest among the three pasted sources. The [Sept. VFX audit](VFX_SENSORY_GRAMMAR_INTEGRITY_AUDIT_2026-09-23.md) should acquire that provenance, while still filtering any conflicting content through later grounded mechanics.
3. **Technology can be overcredited:** old source claims about transmitting emotion, reactive garments, resonance-storing city hardware and AR stabilization by clothing are not validated by the later no-digital-Resonance rule. Ordinary power scarcity is a separate causal mechanism.
4. **U1–U7, W0–W4 and FX:** geography class is not shard danger or a general safety ladder; weather, FX, UARS load, conflict and reader/thread pressure have distinct jobs. The historical Track-1 slab sometimes speaks as though one ladder predicts all the rest.
5. **Economy vocabulary:** “Resonant Exchange” can mean old traded emotion or later combat action; “energy economy” can mean meta load or public electric supply. Never infer money or transferable power from a phrase.
6. **Editorial inflation:** full conversations show in-chat compilations described as “canon” before later approvals, migration and contradiction review. The 72-conversation TAR is excellent provenance, not a canon overwrite.
7. **Production completeness:** `canon/saga_overview.md` and several trilogy cards still contain TODO scaffolding; `source_canon/tech/` and `source_canon/environments/` contain only READMEs; five grids have no rows. A valid schema or deep historical source is not a ready-to-use episode packet.

Before Loom, develop scarcity, shelters, food/water/medicine distribution, authority and transport from the recovered power/travel substrate. **Decision discipline:** Ask for a ruling only when sources conflict on an actual story use. Every ruling should say what earlier variant it supersedes, which books it affects and how a civilian can observe or suffer its consequence.
