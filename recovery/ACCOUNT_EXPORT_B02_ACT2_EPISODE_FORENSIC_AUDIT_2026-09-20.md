## Executive finding

Book 2 Act II contains a strong escalation spine but has **more obvious repetition and
obsolete system implementation than the preceding acts**.

Recovered spine:

**post-pulse NOLA re-entry → resonance-static event → Filament interpretation →
institutional interference → fracture/static hybrid → Filament grounding failure →
recurring cycle recognized → Dominion/Technarc pressure → institutions collide →
consequences interpreted → pattern edges become visible → human entrainment → harmonics
rise → intervals compress → shortest interval → city-scale synchronization threshold.**

No episode is narratively worthless, but this act should **not automatically retain all
16 episode boundaries**.

The strongest compression candidates are:
- E03 + selected E07 material;
- E04 + E08 + E09 institutional-pressure chain;
- E11–E15 acceleration ladder, which currently repeats the same discovery at increasing
  intensity across five episodes.

The act also contains one of the clearest examples yet of old system drift:
“corridor” is simultaneously used as:
1. a physical street/path;
2. an emotional/resonance condition;
3. a U-level pressure state;
4. a proto-geographic Veil taxonomy.

That vocabulary must be untangled before migration.

# XVII. “CORRIDOR” TERMINOLOGY AUDIT

This act demonstrates why “corridor” is currently overloaded.

Old source uses “corridor” for:
- street corridor;
- safehouse-to-street route;
- environmental pressure state;
- U1–U7 scale;
- resonance-space behavior;
- geographic zones;
- institutional “contested domain.”

Current era geography separately uses:
**Veil shards → Neon Zones → Loom Corridors → Echo Nodes.**

Therefore old Book 2 “corridor” cannot automatically map to later formal **Loom Corridor**
taxonomy.

### Required migration rule

For every B2 use of corridor, classify as:
1. literal urban circulation/path;
2. scene pressure envelope;
3. obsolete EBCI U-scale shorthand;
4. actual current Mechanica structure;
5. later-era formal geographic Corridor — almost certainly not appropriate here unless
   separately justified.

Do not globally replace or globally retain.
