Why a single command is unsafe (even if I promise not to compress)

There are three hard limits at play that no prompting can override:

1. Output token ceilings

Even when I “can” output a long response, once content crosses a certain density:

  • the model starts prioritizing structure over content

  • repeated schemas get flattened

  • long middle sections get silently shortened

This is exactly what you saw with the “lossless master MD” attempt.

2. Attention degradation across homogeneous sections

Your cards are:

  • structurally similar

  • thematically dense

  • long

When too many similar blocks appear in one response, the model:

  • preserves headers

  • compresses bodies

  • drops nuance to maintain coherence

This is not visible as an error — it just happens.

3. Tool / session instability (as you already hit)

Even if the model did output everything:

  • long generations are more likely to fail

  • file export sessions expire

  • partial writes happen

You already experienced this.
