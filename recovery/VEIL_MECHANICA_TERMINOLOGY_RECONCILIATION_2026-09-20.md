## 1. Executive finding

The current rules already resolve most Veil terminology questions, but they also expose a
**real internal-era tension** that must be handled deliberately:

Mechanica v4 defines a full global system containing:
- corridor tiers U1–U7;
- CALM → BLOOM → SHARD → RUPTURE → NODE;
- Flicker → Ghostwave → Fracture → Rupture;
- light/sound/geometry/color motifs.

Yet its own Veil escalation rule says:
- subtle;
- low amplitude;
- minimal visible geometry;
- **early shard precursors only (flickers, ghostwaves)**;
- technology mostly stable.

Therefore Veil episode recovery must not read the global vocabulary as permission to
deploy every Mechanica state literally in Books 1–3.

### Governing rule

**System vocabulary defines what exists across the saga. Era permissions define what can
actually manifest on-page.**

For Veil:
**Flicker / Ghostwave are ordinary upper-bound phenomena. Fracture/Shard/Rupture require
specific milestone-level justification rather than casual episode use.**

This resolves most old “micro-Shard / corridor / rupture everywhere” drift without
rewriting Mechanica.

# 2. MICRO-SHARD

## Recovered conflict

B1 recovery contains old references to:
- micro-Shard;
- first micro-Shard milestone;
while older episode language sometimes says no shards/fractures.

Current Mechanica says Veil has:
**early shard precursors only (flickers, ghostwaves).**

Shard progression is:
**Flicker → Ghostwave → Fracture → Rupture.**

There is no formal Mechanica state named **micro-Shard**.

## Disposition

**SUPERSEDED AS FORMAL MECHANICA TERM.**

Do not use “micro-Shard” as a narrator/system label in revised Veil beats unless a current
author ruling explicitly restores it.

Historical “micro-Shard” beats should be mapped by function to:
- Flicker;
- Ghostwave;
- or, if evidence truly requires a persistent break, a milestone-level Fracture exception
  requiring explicit adjudication.

### Important
Do not globally replace “micro-Shard” with “Ghostwave.”
Classify the actual event behavior first.

# 3. SHARD

Current Mechanica uses SHARD both as:
- a resonance state;
- shorthand around fracture/shard geography in later eras.

But Veil-era permissions say **early shard precursors only**.

## Migration rule

In B1–B3:
- do not casually label an event a Shard;
- do not create stable shard geography;
- do not use shard-laced corridors as ordinary Veil locations;
- treat any true SHARD event as an exceptional threshold requiring explicit structural
  milestone support.

Neon is where shards **emerge** as normal saga geography.
Loom is where shards **shape geography**.

This preserves escalation.

# 4. FRACTURE

Mechanica's progression includes **Fracture** as persistent break before Rupture.

Old Veil sources use “fracture” loosely for:
- emotional disagreement;
- geometry flicker;
- event category;
- visible crack;
- system break.

## Migration rule

Use lowercase **fracture** freely as ordinary prose/metaphor where context is nontechnical.

Use formal **Fracture** only for a persistent Mechanica break.

In Veil, formal Fracture should be rare and milestone-controlled.

Do not let old “fracture-static hybrid” automatically create a formal Fracture event.

# 5. RUPTURE

Current Mechanica:
**Rupture = system collapse / violent resonance discharge / catastrophic consequences /
lasting damage / permanent scar creation.**

Veil normally permits only precursors.

But current author ruling + strong historical evidence protect the B3 **Warehouse
Rupture-scale event**.

## Disposition

**WAREHOUSE = EXCEPTIONAL VEIL CLIMAX / TRANSITION EVENT.**

This is not a contradiction if treated as the event that proves the old Veil-era ceiling
is failing and launches Neon.

### Migration rule

Do not scatter Ruptures through Veil.
Reserve formal Rupture for Warehouse unless another author-approved Veil milestone
requires one.

Earlier old “rupture” language should usually become:
- event;
- failure;
- pulse;
- ghostwave;
- pressure spike;
- collapse;
depending behavior.

Warehouse earns the formal term through:
- catastrophic discharge;
- structural collapse;
- death;
- lasting scar;
- era transition.

# 8. CORRIDOR

Mechanica v4 formally defines **Corridors** as spatial stability under resonance pressure,
U1–U7.

However, the saga-era architecture also uses “Loom Corridors” as later formal geographic
language, while old Veil EBCI uses corridor constantly for:
- literal street/path;
- U-tier pressure envelope;
- geographic anomaly;
- scene shorthand.

## Finding

The word itself is canonical in Mechanica.
The problem is **reader-facing era exposure and semantic overload**, not existence.

## Migration rule

### Internal planning / EBCI
U1–U7 corridor tier remains valid as Mechanica metadata.

### Veil prose / dialogue
Characters should generally not speak fluent formal “corridor” taxonomy unless their
knowledge source justifies it.

Prefer ordinary descriptions:
- block;
- route;
- pressure zone;
- unstable area;
- safe passage;
- affected district.

### Later Loom
Formal geographic Corridor language can become explicit as the phenomenon matures.

Thus:
**keep corridor in the engine; ration corridor in Veil prose.**

# 10. DRIFT

“Drift” is not formalized as a Mechanica state in the current authoritative rules.

## Disposition

**VALID CHARACTER WORKING MODEL / NOT FORMAL ONTOLOGY.**

Characters may say drift.
MissingThread may publish “drift.”

This uncertainty is narratively useful.

# 11. HARMONICS

Current Resonance/Mechanica rules explicitly define **Harmonics**:
sound motif for alignment/connection, rare and fragile.

Therefore the term itself is canonical.

Historical misuse occurs when “harmonics” becomes:
- visible field;
- magical force;
- citywide spell;
- generic synonym for resonance.

## Migration rule

Use harmonics narrowly:
**layered sound / alignment / connection / successful mutual grounding.**

Veil constraint:
sound is mostly absent.
Therefore audible harmonics in Veil should be rare, subtle and consequential.

Trip note remains protected:
**harmonics = social warmth, not magic** in his ordinary scenes unless a true resonance
event is separately justified.

## Migration rule

### Public language

This ambiguity is desirable.

# 14. STATIC

Canonical:
buzz/static = friction, tech interference, mixed states.

Mechanica:
technology can distort/degrade/fail but **cannot transmit resonance**.

## Migration rule

Old “resonance static” is viable if it means:
- interference;
- noisy mixed-state perception;
- signal degradation;
- friction.

Not viable:
- resonance traveling through phone/radio/data;
- technology becoming a remote emotional detector;
- static carrying someone's emotional signature.

# 15. TECHNOLOGY

Hard rule:
**technology is a casualty, not a carrier.**

Therefore remove/transform old Veil beats where:
- phones detect Seraphine remotely;
- drones directly damp emotional fields without separate physical mechanism;
- maps/screens transmit resonance;
- data streams contain resonance itself.

Technology may:
- fail;
- glitch;
- record secondary effects;
- correlate human/infrastructure observations;
- carry ordinary information about resonance.

This distinction is especially important for MissingThread.

MT carries **evidence**, never resonance.

# 16. HUMAN ENTRAINMENT / CROWD PHYSICS

Current Mechanica explicitly says:
- crowds multiply patterns;
- emotional states propagate rapidly;
- panic and calm amplify;
- individual control decreases;
- cascades can overwhelm stabilizers.

Current Resonance v1 also says:
**human scale; resonance does not replace agency.**

These rules resolve the B2 synchronization problem.

## Canonical interpretation

Crowds can create:
- emotional contagion;
- cascade;
- convergent movement;
- reduced individual regulation;
- shared anticipation.

Crowds cannot become resonance puppets.

## Migration rule

Use:
**probabilistic/emergent synchronization.**

Avoid:
- everyone blinks together;
- everyone lifts cups together;
- involuntary identical turns;
- citywide exact choreography.

Unless an explicit later Mechanica rule authorizes such a rare event, those old beats are
superseded.

# 17. CITY AGENCY

Mechanica says environment is active.
Resonance v1 says resonance:
**does not want; it reacts.**

Therefore:
“city reacts,” “city breathes,” “city feels,” “city tilts”
may be strong prose but cannot establish consciousness.

## Migration rule

Environment can materially alter outcomes through:
- materials;
- humidity;
- crowd density;
- infrastructure;
- geometry;
- stored pressure/memory.

It cannot:
- choose;
- intend;
- warn;
- punish;
- desire.

Personification = cinematic/POV language by default.

# 18. LIGHT / COLOR / GEOMETRY — rules conflict with Art Canon?

The authoritative Resonance files permit literal expression through:
- light;
- sound;
- geometry;
- color.

The recovered Dec. 9 Art Canon says:
- grounded realism;
- no magic/glam/fantasy cheating;
- “No visible magic. Emotional physics only.”
- light/geometry/sound behave like cinematic metaphors, not supernatural phenomena.

These are **not necessarily contradictory**, but they require an execution distinction.

## Reconciliation

Mechanica/Resonance defines the **allowed expression vocabulary**.

Art Canon defines the **presentation ceiling**:
effects must read as grounded emotional physics, not superhero VFX.

### Veil specifically
Mechanica already says:
- subtle;
- low amplitude;
- minimal visible geometry;
- sound mostly absent.

Therefore in Veil:
- prefer ambiguous physical/environmental manifestations;
- allow attuned POV to notice more;
- use cinematic metaphor freely;
- avoid externally objective glowing grids/halos floating around people.

### Flag
The current `resonance_expression_rules.md` uses some language (“soft halos,” “threads,”
“concentric rings”) that can be misread too literally.
No rules file is modified in this pass, but a future **Art Canon ↔ Resonance Expression
clarification** is warranted.

# 19. GROUNDING RITUALS

Mechanica uses the term “grounding rituals.”

Historical Filament expansion interpreted this too magically.

## Current interpretation

“Ritual” can mean repeatable human practice:
- breathing;
- touch with consent;
- posture;
- music/rhythm;
- food/water;
- familiar environment;
- call-and-response;
- shared attention;
- practiced de-escalation.

It does not imply:
- spell;
- magic circle;
- alignment grid;
- citywide ward.

Thus Mechanica need not change; implementation does.
