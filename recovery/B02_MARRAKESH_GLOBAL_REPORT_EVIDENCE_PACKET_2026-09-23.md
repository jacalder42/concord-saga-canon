## Evidence and custody questions before any E17 assertion

This is a **data request**, not a proposal to invent recordings in each city.

1. Identify the observer or institution for each location and distinguish firsthand observation from relayed rumor.
2. Specify each site's claimed local event: physical effect, human behavior, attuned perception, service-quality degradation, or merely naming a “pulse.”
3. Record an original timestamp if any; distinguish **time of occurrence**, **time first logged**, and **time the report reached NOLA**.
4. State clock source, local offset, drift/error, synchronization method and timestamp edits. “Same second” requires uncertainty substantially less than a second at **all** sites, which the old E17 does not provide.
5. Preserve the raw report or truthful statement that Baz lacks it; record translation, handoffs and revised accounts.
6. Check selection and negatives: which contacted cities did **not** report an event, and which cities were never contacted?
7. Compare ordinary causes at each site and technological status on a continuum (clean operation → noise/lag → intermittent degradation → possible failure). A working radio carries testimony, not Resonance.
8. Predefine what pattern would support correlated worldwide environmental pressure, and what additional evidence would be required for **one cross-site physical event**.
